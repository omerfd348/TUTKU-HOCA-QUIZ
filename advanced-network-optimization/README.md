Advanced Network Optimization Project



📌 Overview

This project analyzes a cargo distribution network using multiple optimization techniques.



&#x20;🎯 Objectives

\- Find shortest delivery path

\- Design minimum cost network

\- Calculate maximum transport capacity



&#x20;🧠 Methods Used

1\. Dijkstra Algorithm (Shortest Path)

2\. Minimum Spanning Tree (MST)

3\. Maximum Flow Algorithm



&#x20;📊 Data Description

Two datasets are used:

\- Distance dataset (km)

\- Capacity dataset (units of cargo)



&#x20;📈 Results

\- Shortest path identifies fastest delivery route

\- MST minimizes infrastructure cost

\- Maximum flow finds highest possible delivery capacity



🔍 Insights

Different algorithms provide different strategic advantages:

\- Speed vs Cost vs Capacity trade-off



&#x20;🧪 Assumptions

\- Static network (no traffic changes)

\- Capacities are fixed

\- Symmetric distances
